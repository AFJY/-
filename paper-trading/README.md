# A股新股民模拟交易盘

这是一个本地纸上交易 MVP：使用虚拟资金、模拟 A 股行情和本地浏览器存储，帮助新股民练习下单、复盘和风险纪律。

## 功能

- 左侧导航：账户概览、交易下单、A 股自选、交易复盘。
- 中央内容区：虚拟资产、模拟行情、买卖下单、持仓盈亏、订单与日志。
- 右侧讨论区：按“新股民训练模式”给出交易习惯提示。
- 交易规则：A 股买入按 100 股一手，内置佣金、印花税和过户费模拟。
- 扩展方向：后续可把 `src/trading-core.js` 的模拟行情替换为真实行情适配器，并增加其他市场。

## 运行

```bash
npm test
npm start
```

启动后打开 `http://localhost:4173`。

## 说明

当前版本不连接真实券商，也不使用真钱；行情为教学模拟行情，只用于训练交易流程和复盘习惯。
